Calculations of mass balance at Lemon Creek Glacier are contained within the main USGS Benchmark Glacier mass balance data release, available at https://doi.org/10.5066/F7HD7SRF. Lemon Creek Glacier is a USGS Benchmark Glacier, and geographically a part of the Juneau Icefield. Data is not duplicated here in order to avoid any potential mismatches or versioning issues. The form of the data and processes used to create it is identical to that described herein.

Prior to version 2.0, this data release contained a separate version of glacier-wide mass balance for Lemon Creek Glacier, calculated by using a lapse rate of -5.0 C/km in place of the -6.5 C/km used at the other benchmark glaciers. The dataset using -5.0 C/km is now presented as the primary Lemon Creek mass balance record, and as such is housed in the main USGS Benchmark Glacier mass balance data release linked above.
